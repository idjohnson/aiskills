# ASD-STE100 Issue 9 Quick Reference Card

## Maximum Constraints & Thresholds
| Parameter | STE Requirement / Limit | ASD-STE100 Rule |
| :--- | :--- | :--- |
| **Procedural Sentence Length** | Max **20 words** | Rule 5.1 |
| **Descriptive Sentence Length** | Max **25 words** | Rule 6.3 |
| **Paragraph Length** | Max **6 sentences** | Rule 6.6 |
| **Paragraph Focus** | Max **1 topic** per paragraph | Rule 6.5 |
| **Noun Clusters** | Max **3 words** | Rule 2.1 |
| **Instructions per Sentence** | Max **1 instruction** (unless simultaneous) | Rule 5.2 |
| **Punctuation** | Semicolons `;` **PROHIBITED** | Rule 8.1 |
| **Contractions** | Contractions (*don't*, *it's*) **PROHIBITED** | Rule 4.2 |
| **Passive Voice** | **PROHIBITED** in procedural text | Rule 3.6 |
| **Modal Verbs** | *should, could, might, may, shall* **PROHIBITED** | Rule 3.4 |
| **-ing Verbs (Gerunds)** | **PROHIBITED** as verbs (allowed only as approved TN/modifier) | Rule 3.5 |
| **Phrasal Verbs** | *carry out, put off, set up, take off* **PROHIBITED** | Rule 9.3 |

---

## Approved Verb Tenses (Rule 3.2)
1. **Imperative (Command)**: *Remove the plate.*
2. **Present Simple (Active)**: *The signal shows the pressure.*
3. **Past Simple (Active)**: *The mechanic installed the pump.*
4. **Future Simple (`will`)**: *The light will flash.*
5. **Past Participle (Adjective only)**: *Install the cleaned valve.*

---

## Common Unapproved Words & STE Alternatives
| Unapproved Word | Part of Speech | Approved STE Alternative | Example Rewritten |
| :--- | :--- | :--- | :--- |
| `utilize` | verb | **USE** | Use the tool to remove the cover. |
| `ensure` | verb | **MAKE SURE** | Make sure that the valve is closed. |
| `terminate` | verb | **STOP** / **END** | Stop the test procedure immediately. |
| `accomplish` | verb | **DO** / **COMPLETE** | Complete the inspection step. |
| `prior to` | preposition | **BEFORE** | Disconnect the cable before you open the hatch. |
| `in order to` | conjunction | **TO** | Press the button to start the engine. |
| `shall` / `should` | modal verb | **MUST** / **CAN** | You must replace damaged seals. |
| `carry out` | phrasal verb | **DO** | Do the daily check. |
| `take off` | phrasal verb | **REMOVE** | Remove the access door. |
| `put off` | phrasal verb | **DELAY** | Delay the maintenance operation. |
| `allow` | verb | **LET** / **PERMIT** | Let the engine cool down. |

## Safety Instruction Formats (Section 7)
- **WARNING** (Injury/Death Risk):
  `WARNING: DO NOT TOUCH THE EXHAUST MANIFOLD. HIGH TEMPERATURE CAN CAUSE SEVERE BURNS.`
- **CAUTION** (Equipment Damage Risk):
  `CAUTION: DO NOT USE AGGRESSIVE SOLVENTS. CHEMICAL ATTACK CAN DAMAGE PLASTIC HOUSINGS.`
- **NOTE** (Information only):
  `NOTE: The battery charge level is displayed on the main monitor.`
