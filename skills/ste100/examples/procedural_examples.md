# ASD-STE100 Procedural Writing Rewriting Examples

## Example 1: Hydraulic Valve Replacement Procedure

### Original Non-STE Text (Violations: passive voice, >20 words, unapproved words, contractions, phrasal verbs):
> "Prior to starting the hydraulic valve removal procedure, it is mandatory that the technician ensures that system pressure has been fully bled off. You shouldn't attempt to disconnect lines without putting on safety goggles. Carry out the removal of the four mounting bolts utilizing the special socket wrench, and then the valve can be taken off."

### STE Analysis & Rule Violations:
1. `Prior to`: Unapproved preposition phrase. Use `Before` [Rule 1.1].
2. `it is mandatory that...`: Passive, wordy. Use imperative `Make sure...` [Rule 5.3].
3. `has been fully bled off`: Passive voice forbidden in procedures [Rule 3.6].
4. `You shouldn't`: Modal `shouldn't` and contraction forbidden [Rule 3.4, Rule 4.2].
5. `putting on`: Phrasal verb. Use `put on` or `wear` [Rule 9.3].
6. `Carry out`: Phrasal verb. Use `Remove` [Rule 9.3, Rule 3.7].
7. `utilizing`: Unapproved verb. Use `with` or `use` [Rule 1.1].
8. `taken off`: Passive voice and phrasal verb. Use active imperative [Rule 3.6].

### STE Approved Rewritten Version:
> 1. Before you start to remove the hydraulic valve, make sure that you release all system pressure.
> 2. Put on safety goggles before you disconnect the hydraulic lines.
> 3. Use the special socket wrench to remove the four mounting bolts.
> 4. Remove the valve.

## Example 2: Fuel Filter Maintenance

### Original Non-STE Text:
> "Inspection of the filter element should be performed every 500 hours; if excessive contamination is observed by the operator, immediate replacement is required."

### STE Approved Rewritten Version:
> 1. Inspect the filter element every 500 hours.
> 2. If you see too much contamination on the filter element, replace the filter element immediately.
