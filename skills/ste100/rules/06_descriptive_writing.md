# Section 6: Descriptive Writing (Rules 6.1 – 6.6)

## Rule 6.1: Gradual Information Presentation
Give information gradually. Present basic overview concepts first before providing detailed technical descriptions.

## Rule 6.2: Logical Structure & Key Phrases
Use key words and key phrases to give your text a logical structure. Ensure headings and topic sentences introduce what follows.

## Rule 6.3: Maximum 25 Words per Sentence
Write short sentences in descriptive text. Use a **maximum of 25 words** in each sentence.

## Rule 6.4: Paragraph Organization
Use paragraphs to organize and group related information.

## Rule 6.5: One Topic per Paragraph
Make sure that each paragraph has **only one topic**. If you introduce a new topic, start a new paragraph.

## Rule 6.6: Maximum 6 Sentences per Paragraph
Make sure that no paragraph contains **more than six sentences**. If a paragraph exceeds six sentences, break it into two separate logical paragraphs.
