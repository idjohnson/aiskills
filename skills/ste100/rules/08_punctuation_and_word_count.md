# Section 8: Punctuation and Word Count (Rules 8.1 – 8.7)

## Rule 8.1: Allowed Punctuation & Semicolon Prohibition
You can use all standard English punctuation marks **EXCEPT the semicolon (;)**.
- Semicolons are strictly forbidden in STE.
- Replace semicolons with periods (`.`), commas (`,`), or restructure into separate sentences.

- **Non-STE**: *Examine the removed parts; replace the damaged ones.*
- **STE Approved**: *Examine the removed parts. Replace the damaged ones.*

## Rule 8.2: Hyphens for Compound Modifiers
Use hyphens (`-`) to connect words that are directly related when they function together as a unit modifier before a noun.
- **Example**: *high-temperature sensor*, *low-pressure valve*, *built-in test*.

## Rule 8.3: Parentheses Usage
You can use parentheses `()` ONLY for:
1. Reference numbers (e.g. figure or item callouts: *Figure 1 (Item 4)*).
2. Defining acronyms on first use (*Simplified Technical English (STE)*).
3. Non-essential explanatory information.

## Rule 8.4: Vertical List Colons & Word Count
In a vertical list, a colon (`:`) has the same effect on word count as a period and indicates that a list follows.

## Rule 8.5: Parenthetical Text Word Count
When you put text in parentheses `(...)`, it **counts as ONE word** in that sentence for sentence word-count calculations.

- **Example**: *Remove the actuator (Figure 2, Item 4) from the bracket.*
  - Word count: "Remove" (1), "the" (2), "actuator" (3), "(Figure 2, Item 4)" (4), "from" (5), "the" (6), "bracket." (7) = **7 words**.

## Rule 8.6: One-Word Counting Rules
Count each of these elements as **ONE word**:
1. Standard numbers and compound numbers (*25*, *1,500*, *3/4*).
2. Units of measurement when combined with numbers (*10 mm*, *50 °C*, *115 V*).
3. Part numbers and model numbers (*PN 45-890-A*, *Model 737*).
4. Standard reference codes (*MIL-STD-810G*).
5. Acronyms (*STE*, *IPC*, *LRU*).
6. Proper names of individuals, companies, or organizations (*Boeing*, *Airbus*).

## Rule 8.7: Hyphenated Words Word Count
Hyphenated words count as **ONE word**.
- **Example**: *built-in* (1 word), *high-pressure* (1 word).
