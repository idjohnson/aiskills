# Section 9: Writing Practices (Rules 9.1 – 9.4)

## Rule 9.1: Sentence Restructuring (No Word-for-Word Substitution)
Use a different sentence construction to write a sentence when a word-for-word replacement is not sufficient or produces awkward, ungrammatical STE text.

- **Non-STE**: *Prior to the initiation of the test procedure, a complete inspection of all fittings must be accomplished.*
- **Word-for-Word (Poor)**: *Before the start of the test procedure, a complete inspection of all fittings must be done.*
- **STE Restructured (Ideal)**: *Before you start the test, inspect all fittings.*

## Rule 9.2: Correct Usage of Approved Words
Use each approved word strictly according to its defined part of speech and permitted definition in the dictionary.

## Rule 9.3: No Phrasal Verbs
When you use two words together, **do not make phrasal verbs**.
Phrasal verbs (verbs combined with prepositions or adverbs like *carry out*, *put off*, *set up*, *blow up*, *go through*, *point out*) are confusing to non-native English speakers.

- **Non-STE**: *Carry out the test.* -> **STE Approved**: *Do the test.*
- **Non-STE**: *Put off the maintenance.* -> **STE Approved**: *Delay the maintenance.*
- **Non-STE**: *Set up the equipment.* -> **STE Approved**: *Prepare the equipment.* / *Assemble the equipment.*
- **Non-STE**: *Take off the cover.* -> **STE Approved**: *Remove the cover.*

## Rule 9.4: Consistent Terminology and Style
When you select terminology or wording, **always use a consistent style** across all documents in a manual set. Never vary vocabulary for stylistic diversity.
